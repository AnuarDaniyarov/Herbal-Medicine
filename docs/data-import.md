# Подготовка и загрузка IMPPAT 3.0

Исходные TSV-файлы IMPPAT остаются локально и не включаются в Git. Поместите их в `data/raw/` либо передайте путь параметром. Скрипт `scripts/Prepare-Imppat.ps1` готовит CSV для растений, соединений, связей, источников, нормализованных мишеней, assay и измерений активности. Перед импортом повторно запустите подготовку, чтобы CSV соответствовали staging-таблицам.

## Подготовить CSV

Из корня проекта в PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Prepare-Imppat.ps1
```

Скрипт кладёт результаты в `data/processed/` и формирует `preparation-report.json`. Для другой папки датасетов:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Prepare-Imppat.ps1 `
  -DatasetDirectory 'D:\путь\к\датасетам' `
  -OutputDirectory '.\data\processed'
```

Подготовка, выполненная 13 октября 2026 года, дала:

| Файл | Записей |
| --- | ---: |
| `plants.csv` | 4 154 |
| `compounds.csv` | 18 314 |
| `plant_compounds.csv` | 196 220 |
| `targets.csv` | создаётся по уникальным парам мишень/организм |
| `assays.csv` | 4 619 |
| `measurements.csv` | 37 068 |

Числа повторной подготовки могут измениться при обновлении исходных файлов. Структуры, отсутствующие в IMPPAT, не импортируются. Повторяющиеся InChIKey в пределах выгрузки оставляются пустыми у последующих записей, чтобы не объединять записи без ручной проверки. Все импортируемые структуры и измерения получают статус `UNVERIFIED`.

## Загрузить в PostgreSQL

1. Запусти приложение один раз с правильными `DB_URL`, `DB_USERNAME` и `DB_PASSWORD`, чтобы Flyway создал схему.
2. Из корня проекта запусти `psql` с доступом к этой же базе:

```powershell
psql -h localhost -p 5432 -U postgres -d medicine_platform -v ON_ERROR_STOP=1 -f .\scripts\import-imppat.sql
```

`psql` запросит пароль PostgreSQL. Если база или пользователь отличаются, замени `-d` и `-U`. SQL выполняется транзакционно и повторный импорт заменяет измерения и связи, привязанные к источнику IMPPAT 3.0.

## Ограничения данных

На официальных страницах IMPPAT 3.0 ресурс опубликован под лицензией Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International (CC BY-NC-ND 4.0). Данные можно использовать с атрибуцией в некоммерческом проекте; подготовленные или преобразованные наборы не следует распространять без проверки условий лицензии и получения необходимых разрешений. Поэтому обработанные CSV исключены из Git и остаются локальными. Перед публичной демонстрацией или публикацией выгрузок проверьте актуальные условия и правила цитирования на [официальной странице IMPPAT](https://cb.imsc.res.in/imppat/) и [странице загрузки](https://cb.imsc.res.in/imppat/download).

IMPPAT просит цитировать статьи версии 1.0 (Scientific Reports, 2018), 2.0 (ACS Omega, 2023) и 3.0 (обновление 2026). Список авторов и публикаций приведён на официальной странице проекта.

- Исходные assay объединены по типу измерения, мишени, организму и единице. Описание условий и исходное поле `Source` сохраняются в `experimental_conditions`, но требуется сверка с первичными источниками.
- IMPPAT bioactivity TSV содержит только значения, однозначно разбираемые как отношение, число и единица. Другие форматы остаются вне подготовленного файла и требуют отдельного разбора.
- Для ограниченного локального AChE-baseline подготовлены фильтрация точных человеческих IC50-измерений, исключение конфликтующих меток и тестовое разделение; см. [docs/ml-baseline.md](ml-baseline.md). Это остаётся exploratory набором: assay conditions и первичные источники требуют дальнейшей проверки, а test split пока случайный, не scaffold-based.
- `data/processed/` исключена из Git: наборы данных не публикуются этим проектом автоматически.
