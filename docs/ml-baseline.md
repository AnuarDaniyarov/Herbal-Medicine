# Локальный ML baseline для AChE

В приложении подключён первый обучаемый ML-провайдер для одного строго заданного сценария: IC50 человеческой ацетилхолинэстеразы (`activityCode=imppat_ic50_e662faf14ac2`). Для прочих типов активности остаётся явно помеченный `DEMO` провайдер.

## Воспроизводимое обучение

Требуются локальные подготовленные файлы `data/processed/compounds.csv` и `data/processed/measurements.csv`, полученные из IMPPAT 3.0. Скрипт не скачивает и не изменяет исходный набор:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Train-AcheBaseline.ps1
```

Скрипт выбирает только человеческую AChE, IC50, точное отношение `=`, единицы nM и соединения со SMILES. Используется бинарная исследовательская метка `IC50 <= 10 000 nM` (эквивалент порога pIC50 5). Соединения с повторными измерениями по разные стороны порога исключаются. Текущий локальный прогон оставил 74 соединения: 37 на класс, 5 конфликтных соединений исключено; 58 пошли на обучение, 16 — в стратифицированную случайную тестовую выборку.

Модель — L2-регуляризованная логистическая регрессия на 256 признаках знакового хеширования 2- и 3-символьных n-грамм SMILES. Артефакт записывается в `data/processed/ache-baseline-model.json`; каталог `data/processed/` игнорируется Git, поэтому модель и производные данные не публикуются автоматически. Backend читает путь из `APP_MODEL_PATH` (по умолчанию `./data/processed/ache-baseline-model.json`).

## Метрики одного тестового разделения

| Метрика | Baseline модели | majority-class |
| --- | ---: | ---: |
| Accuracy | 0,688 | 0,500 |
| Balanced accuracy | 0,688 | — |
| ROC-AUC | 0,781 | 0,500 |
| PR-AUC (average precision) | 0,822 | 0,500 |
| Brier score | 0,239 | — |

Это метрики на 16 молекулах и одном фиксированном случайном разделении, а не надёжная оценка обобщающей способности. Структуры и биоактивности IMPPAT импортированы как `UNVERIFIED`; в исходной таблице отдельные источники могут быть сведены вместе, assay conditions не полностью гармонизированы. Разделение не выполнено по scaffold. Результаты не позволяют делать вывод о лечебном эффекте.

В API результат хранится с `status=ML_BASELINE`, версией модели, вероятностью класса и предупреждением. Это не demo-ответ, но и не подтверждённый научный прогноз. Проверка SMILES ограничена форматом (скобки, ветви, маркеры колец и допустимые символы); полноценная химическая валидация и стандартизация структур не реализованы. Поддерживаются только IC50 AChE человека и обучающий порог 10 µM.

Перед усилением модели нужны ручная проверка первичных источников и assay, нормализация структур RDKit, разделение train/test по химическому каркасу, несколько повторных split-ов, независимый набор и сравнение с химически осмысленным fingerprint baseline. Текущую модель следует использовать только как локальный исследовательский прототип.
